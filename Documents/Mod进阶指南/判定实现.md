# 判定实现
[返回](./引言.md)

介绍 Blacksmith 判定层及动态规则如何插入、覆盖或修饰默认流程。

## 总体结构

1. 技能 DSL → `IDSLSourceFile`（`SourceFile`）
2. `SourceFile.Compile(judger)` → `Intent`
3. `Judger` 收集双方 `Intent`，`TranslateIntentsToResolutions`
4. `JudgeRuleManager` 生成本回合规则链，按阶段执行

完整管线见[项目架构 - 判定引擎](../项目架构.md#8-判定引擎)。

## JudgeStage

可扩展枚举，按 `priority` 升序执行。内置 11 个阶段（0–4096），阶段间差值（8、16...）为 Mod 插入预留空间。

```
OnBegin(0) → AfterResolutionWritten(8) → OnEffectSwaping(16) → OnAttackCanceling(32)
→ OnAttackSwaping(64) → OnApplyingEffect(128) → AfterTransport(256)
→ OnApplyingOthers(512) → OnUpdating(1024) → AfterResult(2048) → OnEnd(4096)
```

## JudgeRuleManager

每个阶段持有 `StageRuleContainer`，内含：

- `_baseRule`：默认基础规则
- `_overrideRules`：覆盖规则（`Build()` 取最后一个）
- `_modifiersBefore` / `_modifiersAfter`：前后修饰器

每阶段执行顺序：Before Modifiers → 核心（Override 或 Base） → After Modifiers

内置默认规则：效果交换、攻击对消（按优先级 1:1，跳过真实伤害和延迟攻击）、攻击交换、效果执行、防御→攻击→资源依次执行、状态更新。

## Mutation

动态规则最小单位：

```csharp
public class Mutation
{
    public int RemainingRounds;
    public int DelayRounds;
    public JudgeStage.CEValue Stage;
    public RuleType RuleType;          // Override 或 Modifier
    public ModifierOrder ModifierOrder; // Before 或 After
    public Action<Community, Community> JudgeRule;
}
```

## DelayRounds 和 RemainingRounds

`TimePass()` 逻辑：先减 `DelayRounds`，归零后减 `RemainingRounds`。`Build()` 只选 `RemainingRounds == 0` 的规则。

- `remainingRounds: 1, delayRounds: 0` → 当回合执行一次，下回合清理
- `remainingRounds: 1, delayRounds: 1` → 下回合才开始生效

## DynamicJudgeRulePool

不直接保存最终规则，而是保存模板（三参数版本 `Action<Community source, Community player, Community enemy>`）。技能实际使用时调用 `Query(source, key)` 固化 `source`，产出标准二参数规则。

## 完整注册链路

```
LinkJudgeRuleDynamic(ruleKey, mutations)  // SourceFile 记住键值对
  → Compile(judger) 触发:
      RegistJudgeRuleDynamic(ruleKey, mutations)  // 模板入池
      AddJudgeRule(_owner, ruleKey)               // 按施法者专门化，插入容器
```

写法详见 [DSL与规则链接](./DSL与规则链接.md)。

## 何时用动态规则

**适合**：改写阶段行为、下回合触发、反击/转移/延迟保护、与默认规则耦合的效果

**不适合**：单纯的攻击/防御/资源变化——用普通 DSL

## 示例：Lancer.Charge()

1. 消耗资源，修改内部计数状态
2. 注册 `OnAttackCanceling` Before Modifier：对手有即时攻击时自动反击
3. 注册 `OnBegin` `delayRounds: 1` Before Modifier：下回合检查重置蓄力

完整拆解见[高级技能模式 - 复杂状态机](../高级技能模式.md#13-复杂状态机-lancercharge)。代码：`Project/Blacksmith/BlacksmithCore/Specific/BuiltInProfessions/Lancer.cs`
